---
title: Longest Vowel Run
difficulty: Easy
tags: [String]
---
Given a string `s` of lowercase English letters, return the length of the longest run of consecutive vowels in `s`. The vowels are `a`, `e`, `i`, `o` and `u`.

**Example 1:**

```
Input: s = "beautiful"
Output: 3
Explanation: "eau" is the longest run of vowels.
```

**Example 2:**

```
Input: s = "rhythm"
Output: 0
```

**Constraints:**

- `0 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
